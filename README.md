# Random Quote Generator

## Автор
Шаповалов Максим Александрович

## Описание
GUI-приложение для генерации случайных цитат с возможностью фильтрации, добавления новых цитат и сохранения истории. Приложение создано с использованием Python и библиотеки tkinter.

## Функциональность
- Генерация случайных цитат из предопределенного списка
- Фильтрация цитат по автору и теме
- Отображение истории сгенерированных цитат
- Добавление новых цитат
- Сохранение и загрузка истории в формате JSON
- Проверка корректности ввода данных

## Требования
- Python 3.6 или выше
- Библиотека tkinter (обычно входит в стандартную установку Python)
